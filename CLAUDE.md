# Project guidance

This is the public TypoStudio personal website, hosted on GitHub Pages.

- `index.html` contains the main interactive landing page.
- `index.md` is the fallback Markdown landing page.
- `_config.yml` selects the `jekyll-theme-minimal` theme.
- `CNAME` sets the custom domain.
- `deploy.sh` commits local changes and pushes `master` to GitHub Pages.

Edit the static HTML directly. Pushes to `master` publish the site.
